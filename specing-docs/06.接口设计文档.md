### 一、通用规范

#### 1.1 Base URL

- 开发环境：`http://localhost:8000`
- 生产环境：`https://<domain>`

#### 1.2 认证方式

| 端 | 方式 | 说明 |
|:---|:---|:---|
| Web 前端 | `Authorization: Bearer <JWT_TOKEN>` | 登录接口获取 Token，24h 过期 |
| Agent 客户端 | `X-API-Key: <API_KEY>` | 由 Agent 配置管理 |

#### 1.3 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

**错误码表**：

| code | 含义 |
|:---|:---|
| 0 | 成功 |
| 4000 | 请求参数错误 |
| 4001 | 未认证（Token 缺失/过期）|
| 4003 | 无权限 |
| 4040 | 资源不存在 |
| 4090 | 资源冲突（如重复提交）|
| 4220 | 请求体验证失败 |
| 5000 | 服务器内部错误 |
| 5001 | LLM 调用失败 |
| 5002 | OCR 处理失败 |

#### 1.4 分页规范

**请求参数**：

```json
{
  "page": 1,
  "page_size": 20
}
```

**响应格式**：

```json
{
  "code": 0,
  "data": {
    "items": [...],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```

- `page` 从 1 开始
- `page_size` 默认 20，最大 100
- 排序字段统一用 `sort_by` + `sort_order`（asc / desc）
