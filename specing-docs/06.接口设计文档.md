### 一、通用规范

#### 1.1 Base URL

- 开发环境：`http://localhost:8000`
- 生产环境：`https://<domain>`

#### 1.2 认证方式

| 端 | 方式 | 说明 |
|:---|:---|:---|
| Web 前端 | `Authorization: Bearer <JWT_TOKEN>` | 登录接口获取 Token，24h 过期 |
| Agent 客户端 | `X-API-Key: <API_KEY>` | 由 Agent 配置管理 |

**JWT Payload 结构**（V3.0 扩展）：

```json
{
  "sub": "admin_uuid",
  "role": "city_admin",
  "city": "伊春",
  "exp": 1720000000
}
```

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| sub | string | 管理员 UUID |
| role | string | 角色：`super_admin` / `city_admin` / `viewer` |
| city | string \| null | 管辖地市（仅 `city_admin` 有值，与 `projects.city` 取值一致） |
| exp | number | 过期时间戳 |

> `role` 和 `city` 写入 JWT 后，后端鉴权依赖可直接从 Token 解析，无需每次请求查库。

#### 1.3 权限规则

| 角色 | 数据范围 | 操作权限 |
|:---|:---|:---|
| super_admin | 全部地市 | 全部操作，含账号管理 |
| city_admin | 可浏览全部地市；仅可操作/确认自己地市的项目 | 确认、修正、导出、审查（限自己地市） |
| viewer | 全部地市（只读） | 仅浏览，不可确认、修正、导出、审查 |

> "操作"包括：人工确认（verify）、修正（PUT）、完成审查、导出报表。"浏览"包括所有 GET 请求。

**鉴权标注约定**：各接口以 `[Auth: 角色]` 标注最低权限要求，`[CityFilter]` 表示 city_admin 自动附加地市过滤。

#### 1.3 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

**错误码表**：

| code | 含义 |
|:---|:---|
| 0 | 成功 |
| 4000 | 请求参数错误 |
| 4001 | 未认证（Token 缺失/过期）|
| 4003 | 无权限 |
| 4040 | 资源不存在 |
| 4090 | 资源冲突（如重复提交）|
| 4220 | 请求体验证失败 |
| 5000 | 服务器内部错误 |
| 5001 | LLM 调用失败 |
| 5002 | OCR 处理失败 |

#### 1.4 分页规范

**请求参数**：

```json
{
  "page": 1,
  "page_size": 20
}
```

**响应格式**：

```json
{
  "code": 0,
  "data": {
    "items": [...],
    "total": 100,
    "page": 1,
    "page_size": 20
  }
}
```

- `page` 从 1 开始
- `page_size` 默认 20，最大 100
- 排序字段统一用 `sort_by` + `sort_order`（asc / desc）

### 五、LLM 分析接口

#### 5.1 推送合同对比分析（UPSERT）

**[Auth: Agent]**

```
POST /api/v1/contract-analysis
```

**请求头**：`X-API-Key: <API_KEY>`

**请求**：

```json
{
  "contract_no": "XYJAEXJCI250500016",
  "rate": 0.1175,
  "rate_level": "正常",
  "similarity": "完全一致",
  "analysis": "前项金额 274 万元，后项金额 241.78 万元，毛利率 11.75%，处于正常区间。各关键条款（付款、交付、验收、违约、质保）前后项表述一致，未发现实质性差异。"
}
```

**响应**：

```json
{
  "code": 0,
  "data": {
    "contract_no": "XYJAEXJCI250500016",
    "updated": true,
    "verified": false
  }
}
```

**后端逻辑**：
- 检查是否已存在同 `contract_no` 的记录
- 存在 → UPDATE（`verified` 重置为 false，`updated_at` 刷新）
- 不存在 → INSERT
